Keyboard Vault Application

Keyboard Vault is a desktop retail management application developed in C# with a local SQLite database. The system supports multiple user roles with distinct features for customers and managers, ensuring secure and efficient workflow.

Customer Features

Customers can browse products, apply promo codes, and place orders using a user-friendly interface. The system includes multithreaded loading for a responsive experience and a local database to retain order history.

Manager Features

Managers have full control over the inventory, employee records, customer details, and promotional offers. Secure login ensures only authorized access to admin features, with tools for reports, analytics, and user management.

Technologies Used

  • C# (WinForms)
  • SQLite Database
  • Threading
  • Object-Oriented Design
